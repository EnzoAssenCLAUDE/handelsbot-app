# handelsbot-app

Alleen de code van een meekijkapp (alleen lezen). Hier staan **geen gegevens en geen sleutels**.
De app vraagt bij het openen om een eigen GitHub-leessleutel en leest daarmee het logboek uit een privé-repository.
De sleutel blijft op het toestel. De bron van deze bestanden staat in de privé-repository (map `app/`).
