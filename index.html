Meekijken met de bot

De app bevat zelf geen gegevens. Hij leest het logboek van de bot uit je privé-repository, met een sleutel die alleen lezen mag. Die sleutel blijft op dit toestel.

Zo maak je de leessleutel
  1. Open GitHub → nieuwe fine-grained token.
  2. Naam: meekijkapp. Vervaldatum: 90 dagen.
  3. Repository access: Only select repositories → alleen de repository van de bot.
  4. Permissions: Contents: Read-only. Optioneel, voor de status van de nachtrun: Actions: Read-only en Variables: Read-only.
  5. Niets anders aanvinken. Geen schrijfrechten.

Met deze sleutel kan niemand handelen, geld opnemen of de bot veranderen. Je Bitvavo-sleutels komen nooit in deze app.

Volgende stap van de bot

Logboek

    De bot beslist één keer per nacht, kort na het sluiten van de dagkaars (01:17 in de winter, 02:17 in de zomer; GitHub start soms later). De koers in deze app is live van Bitvavo; saldo en besluiten komen uit het logboek van de laatste run. De “geschatte waarde nu” is de positie van na die run maal de huidige biedprijs, zonder verkoopkosten. Je echte saldo staat in Bitvavo. “Bitcoin vasthouden” betekent: op de dag van de eerste run voor de volle €100 bitcoin gekocht, 0,36% kosten, nooit verkocht. Resultaten uit het verleden zeggen weinig over de toekomst.
